AI美肌カメラ v1.4.5 - 実機確認項目

初回・権限
1. 初回案内の最後でCAMERA権限ダイアログが出る。
2. CAMERA以外のランタイム権限を要求しない。
3. 拒否後、中央ボタンから再許可できる。
4. Android設定でCAMERAを取消→復帰するとプレビュー停止・権限ボタン表示。
5. 再許可後にカメラが復帰する。
6. 初回案内で戻るジェスチャーをしても未初期化のMain画面へ入らない。

旧版アップグレード
7. DeepSeek対応旧版から上書きした場合、secure_settings/deepseek_api_keyが消える。
8. AndroidKeyStore alias natural_skin_camera_deepseek_keyが削除される。
9. 現行版にAPIキー入力/AI相談/ネットワーク通信が存在しない。

CameraX / 比率
10. 4:3 / 16:9 / 1:1切替が正常。
11. 各比率でプレビューと保存範囲が概ね一致。
12. 1:1でプレビュー・保存JPEGが正方形。
13. 比率変更直後にシャッターを連打しても旧比率/未接続UseCaseで撮影しない。
14. 前後切替正常。
15. 前面非搭載端末では背面起動・前後ボタン無効。
16. 背面に切替→回転しても背面を維持。
17. ホーム→復帰で不要なCameraX再バインド/暗転を繰り返さない。

向き・反転
18. インカメラ見たまま保存ON/OFFを縦向きで確認。
19. 同設定を横向きで確認。
20. 90/180/270度相当の端末向きでも保存画像が天地逆・転置にならない。
21. 補正前JPEGも同じ向き・比率になる。

美肌
22. 美肌ON/OFF、0〜30、3プリセット。
23. 美肌OFFはCameraX JPEGを再圧縮せず保存。
24. 顔未検出は背景を誤加工せず元JPEG保存。
25. 複数人の顔で顔領域以外への加工が目立たない。
26. 暗所/横顔/小さい顔で検出失敗しても撮影自体は成功。
27. ML Kit初期化/処理失敗時も元JPEG救済できること（可能ならテストビルドで故障注入）。
28. メモリ逼迫時にアプリ落ちではなく元JPEG救済へ進むこと。

保存
29. 通常写真がPictures/AI美肌カメラへ保存。
30. 補正前JPEG ON + 美肌成功時だけOriginalへ追加保存。
31. 美肌OFF/顔未検出ではOriginalへ同内容を重複保存しない。
32. ストレージ不足等の失敗後にギャラリーへ壊れたpending画像が目立って残らない。
33. 強制終了テスト後、次回起動でcache/capture_*.jpg残骸が消える。
34. 「写真」ボタンで直近写真、無効ならギャラリーへフォールバック。

タイマー・入力
35. 3/5/10秒タイマー。
36. タイマー数字が各比率/前後/縦横で中央に見える。
37. タイマー中は向き固定、撮影後に復帰。
38. タイマー中にホームへ行くと安全にキャンセル。
39. 音量＋/−で撮影。
40. 権限未許可/カメラ準備中/保存中は音量キーが通常の音量調整として働く。
41. 撮影音が鳴る。
42. 保存中の戻るボタン/戻るジェスチャーでActivityが終了しない。

UI
43. 320〜360dp幅で上部4ボタン、下部操作が押せる。
44. 横画面でプレビューが操作部に覆われない。
45. 主要タップ領域が小さすぎない。
46. Android 15/16でステータス/ナビゲーションバーにUIが潜らない。
47. 黒ナビゲーションバー上のシステムアイコンが見える。
48. グリッド設定変更→戻るで即反映。

連続・ライフサイクル
49. 50回程度の連続撮影でメモリ増大/停止がない。
50. 撮影直後ホーム→復帰でクラッシュしない。
51. 撮影処理中に画面回転やバック操作を繰り返しても保存状態が壊れない。

ビルド/静的
52. GitHub Actionsの:app:lintDebug成功。
53. GitHub Actionsの:app:assembleDebug成功。
54. merged ManifestにINTERNET / ACCESS_NETWORK_STATEがないことを最終確認。
55. 実APKをネットワーク監視して、通常撮影・設定・顔検出で外部通信が0であることを確認。

回帰確認追加
56. 初回表示直後にViewPortが未確定でも、黒画面のまま固定されず次の描画でプレビューが開始する。
57. ViewPort未確定時に50ms等の定期ポーリングが発生しない。
58. 複数人撮影で小さく写る顔が過剰に平坦化されず、各顔以外の背景を加工しない。
59. ML Kit Taskを故障注入でキャンセル/開始例外にしても撮影状態が固まらず元JPEGを保存する。
